## API surface

Starship states that its APIs let a partner create delivery jobs, load robots, obtain delivery
status updates and handle delivery cancellations, and that Starship provides "a full developer
toolkit, documentation and support". None of that is published to the open web:

- There is no developer portal, API reference or getting-started page. The complete site sitemap
  (https://www.starship.xyz/page-sitemap.xml) lists 43 pages and none of them is developer-facing.
- No OpenAPI, Swagger, GraphQL SDL, AsyncAPI, Protobuf or WSDL contract could be found on any
  Starship host.
- api.starship.xyz is a live origin but returns a plain-text 404 for every unauthenticated path
  probed, including /openapi.json, /swagger.json, /graphql, /api-docs, /docs and /mcp.
- No MCP server, no A2A agent card, and no /.well-known/ document of any kind is served.
- Access route: partners request the developer documentation commercially, via
  https://www.starship.xyz/contact/ or business@starship.co.
